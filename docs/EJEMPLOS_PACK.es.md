# Paquete de ejemplos Alset Studio (v2)

Los ejemplos antiguos se reemplazaron por apps base **reales**.

| Id | Nombre | Para qué sirve |
|----|--------|----------------|
| abaco-shell | ÁbacoPhy Shell | Contabilidad, drawer, KPIs, estados |
| alsetos-home | AlsetOS Home | Launcher de apps del sistema ANS |
| sales-hub | Sales Hub | Ventas multi-rol, chat por pulse |
| la-tati | La Tati | Gestora / catálogo |
| state-crud | Estados + CRUD | setOp, list custom, REST |
| mind-deck | Mind · Zyrion | Lógica ternaria |
| mesh-live | Mesh + Pulsos | Red y consumers |
| media-map | Media + Mapa | Video, audio, OSM |
| identity | Identidad ANS | Login, roles, gate |
| future-agent | Agent Desk | Agentes + mind |
| inventory | Inventario | SKU y unidades |
| city | Servicios ciudad | Reportes municipales |
| live-ops | Live Ops | WebRTC / hub |
| clean-arch | Clean Architecture | Capas de trabajo |

## Uso

1. **Ejemplos** → Cargar  
2. **Correr preview**  
3. **Desplegar** → `/apps/<id>/`  
4. En nodo Alset: registrar y abrir `/w/<id>.app.ans`

## Estilo

Las apps en preview usan tokens alineados a **ÁbacoPhy** (oro `#f4b400`, cards elevadas, botones pill, radius 14).
