LispAI declara UI y parches sin tocar el mouse. Ejemplos: (set-prop n1 text "Hola") o un árbol (ui (column …)).

Backend embebido del studio (Go). Úsalo desde componentes api, formularios o fetch manual.

  • GET /v1/health — vida del runtime
  • GET|POST|DELETE /v1/data — CRUD en memoria
  • POST /v1/auth/login — token (admin/demo/master)
  • POST /v1/deploy — genera PWA en /apps/<name>/
